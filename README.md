# What Happened in 1971? — Interactive Economic Charts

Recreates the economic divergence charts from [wtfhappenedin1971.com](https://wtfhappenedin1971.com) as interactive D3.js visualizations.

## Data Sources

All data is fetched from the [FRED API](https://fred.stlouisfed.org/docs/api/fred/) (Federal Reserve Economic Data), which aggregates BLS, BEA, Census, Treasury, and World Bank data.

### Series Reference

| Chart | FRED ID | Series Name | Date Range | Notes |
|-------|---------|-------------|------------|-------|
| **Wages vs. Productivity** | `OPHNFB` | Labor Productivity (Output per Hour), Nonfarm Business | 1947–2026 | BLS via FRED |
| | `COMPRNFB` | Real Hourly Compensation, Nonfarm Business | 1947–2026 | BLS via FRED (inflation-adjusted) |
| **Real GDP Per Capita** | `A939RX0Q048SBEA` | Real GDP per capita | 1947–2026 | BEA via FRED |
| **Federal Debt / GDP** | `GFDGDPA188S` | Gross Federal Debt as Percent of GDP | 1939–2025 | Treasury via FRED |
| **CPI (Inflation)** | `CPIAUCSL` | Consumer Price Index, All Urban Consumers, All Items | 1947–2026 | BLS via FRED |
| **Gini Coefficient** | `SIPOVGINIUSA` | GINI Index for the United States | 1963–2024 | World Bank via FRED |
| **Top Tax Rate** | `IITTRHB` | Individual Income Tax Rate, Highest Bracket | 1913–2018 | IRS via FRED |
| **Personal Savings Rate** | `PSAVERT` | Personal Saving Rate | 1959–2026 | BEA via FRED |
| **Stock Market vs. Wages** | `SP500` | S&P 500 | 2016–2026 | **LIMITED** — FRED only has daily S&P 500 from 2016 |
| | `AHETPI` | Avg Hourly Earnings, Production & Nonsupervisory | 1964–2026 | BLS via FRED |
| **Trade Balance** | `NETEXP` | Net Exports of Goods and Services | 1947–2026 | BEA via FRED |
| **Housing Affordability** | `USSTHPI` | FHFA All-Transactions House Price Index, U.S. | 1975–2026 | FHFA via FRED; starts after 1971 |

### Data Limitations

- **Stock Market:** FRED's S&P 500 series (`SP500`) only begins in September 2016. The historical DJIA monthly index (`M1109BUSM293NNBR`) ends in December 1968. Neither provides continuous coverage across 1971. To get full historical stock data, consider sourcing from [Robert Shiller's Yale dataset](https://bear.stern.nyu.edu/~lshiller/data/) or [Yahoo Finance](https://finance.yahoo.com/quote/%5EGSPC/history/).
- **Housing:** FHFA index starts January 1975. The 1971 baseline is extrapolated from the first available data point.
- **Gini:** World Bank data starts 1963; earlier U.S. Gini data exists at the Census Bureau but is not available via FRED.
- **Top Tax Rate:** IRS data ends 2018 (TCJA reform). Post-2018 rates are constant at 37%.

### Data Processing

The `scripts/fetch-data.js` script:
1. Fetches monthly/quarterly observations from FRED
2. Averages to annual frequency
3. Normalizes to `1971 = 100` for indexed comparisons (where applicable)
4. Saves as JSON to `data/`

## Tech Stack

- **React 18** + **Vite** — fast dev server, small production bundles
- **D3 v7** — SVG rendering, axis scaling, annotations, zoom/pan
- **No wrapper libraries** — D3 used directly in `useEffect` with `useRef`

## Development

```bash
npm install
npm run dev          # dev server on localhost:5173
npm run build        # production build to dist/
npm run preview      # preview production build
```

### Refresh Data

```bash
# Set your FRED API key (get free key at https://fred.stlouisfed.org/docs/api/api_key.html)
export FRED_API_KEY="your_key_here"
node scripts/fetch-data.js
```

## Deployment

GitHub Actions workflow (`.github/workflows/deploy.yml`) builds and deploys to GitHub Pages on push to `main`.
